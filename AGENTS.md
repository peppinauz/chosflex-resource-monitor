Chrome OS Flex system resource monitor
----
Entorno
- ChromeOs Flex en Macbook Air de 2018
- Al habilitar las opciones de desarrollador de ChromeOs Flex se corre una maquina virtual Debian (Crostini) que permite lanzar contenedores docker 

Descripcion

- Quiero hacer un servidor en python y una aplicacion que monitorice los recursos del sistema: CPU, memoria, ocupacion de disco y trafico de red
- En otro apartado quiero tener ver los contenedores que se estan corriendo
- La pagina web sera accesible desde ChromeOS Flex
- Se refrescara automaticamente cada 5 segundos
