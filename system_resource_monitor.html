Crostini Native Telemetry Bridge

Bridge real Debian Linux container metrics directly into this Dashboard

ChromeOS sandboxes web browsers for security. To feed exact CPU core frequencies, real Linux RAM usage (`/proc/meminfo`), network interfaces (`/proc/net/dev`), and Crostini LXC disk storage (`df -h`), run this lightweight Python HTTP bridge inside your Crostini terminal:

1-Line Setup Command (Run inside Debian Terminal):
curl -sSL https://raw.githubusercontent.com/crostini-monitor/agent/main/serve.py | python3
Or create `crostini_agent.py` manually: 
from http.server import HTTPServer, BaseHTTPRequestHandler
import json, subprocess, os

class StatsHandler(BaseHTTPRequestHandler):
    def do_GET(self):
        self.send_response(200)
        self.send_header('Access-Control-Allow-Origin', '*')
        self.send_header('Content-Type', 'application/json')
        self.end_headers()
        
        # Read system metrics
        mem = open('/proc/meminfo').read()
        stat = open('/proc/stat').read()
        df = subprocess.check_output(['df', '-h', '/']).decode()
        
        payload = {"status": "ok", "mem": mem, "stat": stat, "df": df}
        self.wfile.write(json.dumps(payload).encode())

print("Crostini Agent Listening on http://localhost:8050")
HTTPServer(('0.0.0.0', 8050), StatsHandler).serve_forever()
Endpoint: http://localhost:8050
